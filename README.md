Entry for [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) on make.fun.

A cron job hands in its notice: it refuses to keep running at 2:30 a.m. on the one night a year 2:30 a.m. happens twice — the daylight-saving fall-back — when nobody warned it.

`main.ts` writes the single resignation line to `/output/entry.txt`.
